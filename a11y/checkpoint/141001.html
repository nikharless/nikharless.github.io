Basic Requirements and Best Practices

= Requirement
= Best Practice

  • Vertical-scrolling content must be viewable without horizontal scrolling when the viewport is set to 320 CSS pixels wide.
  • Horizontal-scrolling content must be viewable without vertical scrolling when the viewport is set to 256 CSS pixels high.
  • The content must not be cropped or rendered unreachable when the viewport is set to 320 CSS pixels wide or 256 CSS pixels high.
  • Videos should resize to fit within the viewport.
  • Images should resize to fit within the viewport.

Overview

The content must be viewable and usable without scrolling in two dimensions when the viewport is set to 320 CSS pixels wide or 256 CSS pixels high.

Exceptions may include:

  • Maps
  • Diagrams
  • Video
  • Games
  • Presentations
  • Data tables (not individual cells)
  • Interfaces where it’s necessary to keep toolbars in view while manipulating content

Web Test Procedure

Desktop

  1. Open the page in Chrome at the actual size (e.g., no zoom, magnification, or user-supplied CSS features are turned on).
  2. For vertical scrolling content, resize the browser viewport to either:
    • 640px width at 200% zoom, OR
    • 1280px width at 400% zoom
  3. Verify that you can see all the content on the page without scrolling horizontally.
  4. For horizontal scrolling content, resize the browser viewport to either:
    • 512px height at 200% zoom, OR
    • 1024px height at 400% zoom
  5. Verify that you can see all the content on the page without scrolling vertically.

Mobile

This checkpoint does not apply to mobile, as horizontal scrolling with pinch-zoom is not something the developer can control.

PDF Test Procedure

  1. View the document at 200%.
  2. Select View > Zoom > Reflow.
  3. Verify that the content remains readable when reflowed.
