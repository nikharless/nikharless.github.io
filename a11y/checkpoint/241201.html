Basic Requirements and Best Practices

= Requirement
= Best Practice

  • No part of a focused element may be hidden by other content.

Overview

Some examples of content that may hide focus include:

  • Sticky footers
  • Sticky headers
  • Modeless dialogs

Testing Logic

As you navigate through the page using the keyboard, is any part of the keyboard focus hidden behind other content?

  • Yes; See {{ site.data[page.criterion][page.criterion]["24120101"].name }}.
  • No; PASS

Web Test Procedure

  1. Using only the keyboard, navigate to and interact with all interactive elements and widgets.
  2. Verify that the element in focus is never obscured by other author-created content.
