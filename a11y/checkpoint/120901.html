Basic Requirements and Best Practices

= Requirement
= Best Practice

  • Live audio must have a text equivalent (captions or transcript).
  • Text equivalent (captions or transcript) must be accurate.
  • Text equivalent (captions or transcript) must include all dialogue and narration.
  • Text equivalent (captions or transcript) must include important sounds.
  • Text equivalent (captions or transcript) must identify speakers.

Overview

Note: This criterion does not apply to two-way audio calls between multiple individuals.

Testing Logic

Does the page contain any live audio broadcasts?

  • Yes; Does the audio broadcast have a procedure in place to provide real-time text equivalents (captions or transcript)?
    • Yes; Is the text equivalent accurate?
      • Yes; Do the text alternatives include all dialogue?
        • Yes; Do the text alternatives include important sound effects?
          • Yes; Do the text alternatives identify the speakers?

Web Test Procedure

  1. Locate each live audio element on the page.
  2. Verify that there is a procedure in place to provide real-time text alternatives.
  3. Verify that the text alternatives meet the requirements above.
