Basic Requirements and Best Practices

= Requirement
= Best Practice

  • Color must not be used as the only visual means of conveying information.

Overview

Some ways to convey information without relying on color:

  • Text
  • A symbol
  • Font weight
  • Pattern
  • Contrast

The alternate visual means:

  • Must be in addition to any programmatic alternatives for assistive technology
  • Must be visible onscreen (e.g., not only on mouse hover)

Note: Visited links cannot be styled by the author, so this checkpoint does not apply.

Testing Logic

Is there any content that relies on color to convey meaning?

  • Yes; Is color used as the only means to indicate an action?
    • Yes; See {{ checkpoint_data["14010102"].name }}.
    • No; Is color used as the only means to prompt a response?
      • Yes; See {{ checkpoint_data["14010103"].name }}.
      • No; Is color used as the only means to distinguish a visual element?
        • Yes; See {{ checkpoint_data["14010104"].name }}.
        • No; See {{ checkpoint_data["14010101"].name }}.
  • No; This checkpoint is not applicable.

Web Test Procedure

  1. Examine the page for any elements where color is used to convey information, indicate an action, prompt a response, or distinguish a visual element.
  2. You may use ANDI: color contrast and activate the "grayscale" button to render the page in grayscale.
  3. Verify that the information conveyed by color is also conveyed visually without relying on color.
