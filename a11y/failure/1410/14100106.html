Expected Result

When horizontal-scrolling content is resized to 256 CSS pixels high, vertical scrolling is not required.

Actual Result

When the content is resized to 256 CSS pixels high, vertical scrolling is required to access all the content.

Solution

  • Use a layout which reflows when the screen size changes, AND
  • Use relative measurements for fonts, controls, images, and containers

Passing Example

Disabilities Affected

  • Visual Impairment: Users with visual impairments who have to enlarge the page can become disoriented if they have to scroll back and forth to read and use content.
  • Cognitive Impairment: Users with certain cognitive impairments can become disoriented if they have to scroll back and forth to read and use content.
