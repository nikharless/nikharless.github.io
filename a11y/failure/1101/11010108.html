Expected Result

The text alternative conveys the information in the current image.

Actual Result

When a meaningful image changes, assistive technology users continue to receive a text alternative for the previous image and do not receive the current image’s information.

Solution

Update the text alternative when the image’s information changes so it conveys the information in the current image.

Failing Example

Button changes image but not text alternative

When the image changes, its text alternative does not update, so the changed image still describes the original image and does not accurately describe the new image.

How a screen reader reads it:

  • Default image:
    • NVDA 2026 / Chrome 158: "graphic, Blue fish"
  • Second image:
    • NVDA 2026 / Chrome 158: "graphic, Blue fish"

<img src="fish.png" id="myImageFail" alt="Blue fish">
<input type="button" onclick="changeImage()" value="Change Image">
<script>
    function changeImage() {
        var image=document.getElementById('myImageFail');
        if (image.src.match("trout.png")) {
            image.src="fish.png";
        } else {
            image.src="trout.png";
        }
    }
</script>

Passing Example

Button Changes Image

This button uses JavaScript to change the alt value along with the displayed image so that the text alternative remains accurate for the current image.

How a screen reader reads it:

  • Default image:
    • NVDA 2026 / Chrome 158: "graphic, Blue fish"
  • Second image:
    • NVDA 2026 / Chrome 158: "graphic, Trout"

<img src="fish.png" id="myImage" alt="Blue fish">
<input type="button" onclick="changeImage()" value="Change Image">
<script>
    function changeImage() {
        var image=document.getElementById('myImage');
        if (image.src.match("trout.png")) {
            image.src="fish.png";
            image.alt="Blue fish";
        } else {
            image.src="trout.png";
            image.alt="Trout";
        }
    }
</script>

Disabilities Affected

  • Blindness/Visual Impairment: People who cannot perceive the image need its current information conveyed in text.
  • Cognitive Impairment: People who have difficulty understanding images may benefit from having a text description that accurately describes the image.
