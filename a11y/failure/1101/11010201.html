Expected Result

The control has an accessible name that describes its purpose, and the <img> element has an alt attribute. When the control provides the name, the image is hidden from assistive technology with alt="".

Actual Result

Assistive technology does not receive a name that identifies the control’s purpose.

Solution

Add an alt attribute to the <img> that concisely conveys the control's purpose.

Failing Example

Image as link

The image is the only content in this link, and neither the link nor the image have an accessible name.

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "Unlabeled graphic link"
  • NVDA 2026 / Firefox 160: "ourparks.org graphic link"

<a href="https://ourparks.org/">
    <img src="our-parks-logo-dark.svg">
</a>

Image button

The image is the only content in this button, and neither the button nor the image have an accessible name.

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "button"
<button>
    <img src="forward-arrow-icon.png">
</button>

Passing Example

Preferred: Link image with alt text

A text alternative describing the link is added to the image.

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "Our Parks graphic link"

<a href="https://ourparks.org/">
    <img 
        src="our-parks-logo-dark.svg" 
        alt="Our Parks">
</a>

Preferred: Button image with alt text

A text alternative describing the button's function is added to the image.

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "Share graphic button"
<button>
    <img src="forward-arrow-icon.png" alt="Share">
</button>

Button with aria-label

An aria-label is added to the button.

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "Share button"
<button aria-label="Share">
    <img src="forward-arrow-icon.png">
</button>

Disabilities Affected

  • Blindness/Visual Impairment: People using assistive technology need to know what action the control performs.
  • Cognitive Impairment: People who have difficulty understanding images may benefit from having a text alternative describing the control.
