Expected Result

Text alternatives refer to the location of the transcript.

Actual Result

A video element has a text alternative and transcript, but the text alternative does not refer to the location of the transcript.

Solution

Add a reference to the location of the transcript to the text alternative.

Failing Example

Passing Example

Disabilities Affected

Blind and visually impaired users should be informed that a transcript is available and where it is located.
