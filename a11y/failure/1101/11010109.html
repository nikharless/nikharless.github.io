Expected Result

A meaningful image has a text alternative that conveys the same information as the image.

Actual Result

Assistive technology users cannot access the information conveyed by the image.

Solution

Add Alternate Text to the image either in the source document or directly in the PDF.

Adobe Acrobat Pro

  1. Select Prepare for accessibility > Add alternate text.
  2. Right-click on the image and select Edit Alternate Text....
  3. In the "Set Alternate Text" dialog, enter text which describes the function or destination of the control.

Note: Different versions of Adobe Acrobat may not exactly match these instructions.

Example

Image with Caption

This image has a <Caption> nested within the <Figure> tag. While this is the recommended structure, screen readers do not appear to read both the Alternate Text and the Caption, but the PDF fails the accessibility check if there is no Alternate Text. A workaround is to include the Caption text in the Alternate Text.

Disabilities Affected

  • Blindness/Visual Impairment: Users need to have a text alternative for meaningful images so that the images can be interpreted by assistive technology such as screen readers and braille devices.
  • Cognitive Impairment: Users who have difficulty understanding images may benefit from having a text description.
