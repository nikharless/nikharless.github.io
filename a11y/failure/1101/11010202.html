Expected Result

The SVG control has an accessible name that describes its purpose.

Actual Result

When the control receives focus, assistive technology does not announce a name that identifies its purpose.

Solution

Give the <svg> control an accessible name that describes its purpose, using a direct child <title>, aria-label, or aria-labelledby.
  1. Add a <title> element as the first child of the the <svg> element, and enter the text alternative within.
  2. Add a unique id to the <title> element.
  3. Add aria-labelledby to the <svg>, and point it to the <title> element's id.
  4. Add a role to the <svg> to ensure that screen readers recognize it and read the text alternative.

Failing Example

Image as link

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "link"

<a href="a11y_policy.html">
    <svg>
        <g ...>
        ...
    </svg>
</a>

Button image

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "button"
<svg tabindex="0" role="button" width="24" height="24">
    <path ...>
</svg>

Passing Example

Preferred: Image as link with <title>

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "Accessibility Policy graphic link"

<a href="a11y_policy.html">
    <svg role="img" aria-describedby="a11yPolicy">
        <title id="a11yPolicy">Accessibility Policy</title>
        <g ...>
        ...
    </svg>
</a>

Preferred: Button image with <title>

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "Share button"
<svg tabindex="0" role="button" width="24" height="24" aria-labelledby="share-title">
    <title id="share-title">
    <path ... >
</svg>

Button image with aria-label

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "Share button"
<svg tabindex="0" role="button" width="24" height="24" aria-label="Share">
    <path ... >
</svg>

Disabilities Affected

  • Blindness/Visual Impairment: People who use assistive technology need to know what action the control performs.
  • Cognitive Impairment: People who have difficulty understanding images may benefit from having a text alternative describing the control.
