Expected Result

Information conveyed by CSS background images is available in text.

Actual Result

People who cannot see the background image cannot access the information it conveys.

Solution

Depending on the context, different solutions may be applicable such as the following:
  • Provide the information conveyed by the background image as text in the page content.
  • If the image needs its own text alternative, use a foreground image with appropriate alternative text.
  • If the image container is for the sole purpose of displaying the image, such as an icon font, add role="img" to the container and an aria-label describing the purpose of the image.

Failing Examples

CSS icons

This icon has meaning, but it is displayed as a background image, so that meaning is not conveyed to assistive technology.

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: No announcement

This information is out of date. 

<i class="fa-solid fa-circle-exclamation"></i> This information is out of date.

Background Image with Text

Assume this background image's text relates to the text content placed on top of it. In this case, the background image is meaningful and needs a text alternative.

If the element with the background image did not have other content inside it, you could use role="img" and aria-label to give it a text alternative. However, in that case, there's no reason not to just use the simpler <img alt="..."> markup.

Since the element does contain other content, it cannot have a text alternative. The screen reader will not read both.

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: No announcement
Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Rhoncus aenean vel elit scelerisque mauris.
<div style="background-image: url("time-for-change.jpg"); width: 649px; height: 427px;">
    <div class="divText">
        Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Rhoncus aenean vel elit scelerisque mauris.
    </div>
</div>

.divText {
    width: 249px;
    margin-right: 400px;
    padding: 80px 0 20px 20px;
    color: white;
    background-color: rgba(0,0,0,0.5);
}

Passing Examples

CSS icon with aria-label

Adding an aria-label and role="img" make the meaningful icon accessible.

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "graphic, Alert"

This information is out of date. 

<i aria-label="Alert" role="img" class="fa-solid fa-circle-exclamation"></i> This information is out of date.

Image with Overlaid Text

The image needs to be marked up as a regular image, and the block of text as a separate element positioned with CSS.

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "graphic, Time for Change"
Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Rhoncus aenean vel elit scelerisque mauris. 
<div style="position: relative; width: 649px; height: 427px;">
    <img src="time-for-change.jpg" alt="Time for Change" class="overlap-image">
    <div class="divText overlap-image">
        Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Rhoncus aenean vel elit scelerisque mauris.
    </div>
</div>

.overlap-image {
    position: absolute;
    top: 0;
}

.divText {
    width: 249px;
    margin-right: 400px;
    padding: 80px 0 20px 20px;
    color: white;
    background-color: rgba(0,0,0,0.5);
}

Disabilities Affected

  • Blindness/Visual Impairment: People who cannot perceive the image need to have a text alternative so that the image can be interpreted by assistive technology such as screen readers and braille devices.
  • Visual Impairment: People who suppress background images, including some users of high contrast settings, can lose information conveyed only through the background.
  • Cognitive Impairment: Users who have difficulty understanding images may benefit from having a text description.
