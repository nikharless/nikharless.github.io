Expected Result

A meaningful emoji has a text alternative that conveys the same information as the image.

Actual Result

Assistive technology users cannot access the meaning conveyed by the emoji.

Solution

Add a text alternative which describes the purpose of the meaningful emoji.
  1. Add a <span> tag around the emoji.
  2. Add role="img" to the <span>.
  3. Add an aria-label to the <span>.
  4. Set the value to a text alternative that makes sense in context.

Failing Example

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "Globe showing Asia Australia, Peace symbol"

World Peace

🌏☮️

🌏☮️

Passing Example

World Peace

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "graphic, World, graphic, Peace"

🌏☮️

<span role="img" aria-label="World">🌏</span><span role="img" aria-label="Peace">☮️</span>

Disabilities Affected

  • Blindness/Visual Impairment: People who cannot perceive the image need its intended meaning conveyed in text.
  • Cognitive Impairment: People who have difficulty understanding images may benefit from having a text description that conveys the intended meaning.
