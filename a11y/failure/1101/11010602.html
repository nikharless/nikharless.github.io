Expected Result

Each video element has a text alternative that summarizes its purpose.

Actual Result

A video element does not have a text alternative.

Solution

Add a text alternative that summarizes the content of the video:
  • Add an aria-label attribute to the element, OR
  • Add an aria-labelledby attribute to the element, set to the id value of the text to use as a label

Failing Example

HTML <video>

<video width="320" height="240" controls>
    <source src="blue-tit.mp4" type="video/mp4">
    Your browser does not support the video tag.
</video>

Passing Example

HTML <video>

<video width="320" height="240" controls aria-label="blue tit chirping">
        <source src="blue-tit.mp4" type="video/mp4">
        Your browser does not support the video tag.
    </video>

Not Applicable

  • Missing audio description or text transcript:
    File under {{ site.data[page.criterion][page.criterion]["12010201"].name }}.

Disabilities Affected

Blind and visually impaired users need to have a text alternative to embedded video so they know what it is without having to play it.
