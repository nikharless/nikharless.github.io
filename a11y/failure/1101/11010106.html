Expected Result

The text alternative conveys the information or purpose the image provides in context.

Actual Result

Assistive technology users receive a text alternative that does not convey the information or purpose provided by the image.

Solution

Revise the text alternative so it conveys the information or purpose the image provides in context.

Failing Examples

Literal description

Often images are used to mean something abstract, so a literal description, such as "exclamation mark in a circle" for the image below, does not provide useful information.

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "graphic, exclamation mark in a circle"

This information is out of date.

<img src="alert.png" alt="exclamation mark in a circle">

Context matters

The image in the following example might literally be described as "an old photograph of a mustached man in a cap driving an old car with no roof or windows". However, that may not convey the information intended by its context.

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "graphic, an old photograph of a mustached man in a cap driving an old car with no roof or windows"
<img src="itala.jpg" alt="an old photograph of a mustached man in a cap driving an old car with no roof or windows">

Note: Multiple methods of providing a text alternative applied to the same image may produce unexpected results. For example, if both an alt value and an aria-label are provided, the aria-label will override the alt value.

Passing Examples

Meaningful description

The image below indicates a warning, so the alt text should convey this information.

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "graphic, Warning"

This information is out of date.

<img src="alert.png" alt="Warning">

In an article about old cars

If the context of the page is old cars, alt text should probably describe the type of car, such as "1907 Itala motor car."

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "graphic, 1907 Itala motor car"
<img src="itala.jpg" alt="1907 Itala motor car">

In an article about Prince Scipione Borghese

If the context is Prince Scipione Borghese, the type of car is likely irrelevant. Something like "Borghese's chauffeur, Ettore Guizzardi" would be more appropriate.

How a screen reader reads it:

  • NVDA 2026 / Chrome 158: "graphic, Borghese's chauffeur, Ettore Guizzardi"
<img src="itala.jpg" alt="Borghese's chauffeur, Ettore Guizzardi">

Disabilities Affected

  • Blindness/Visual Impairment: People who cannot perceive the image need its relevant information or purpose conveyed in text.
  • Cognitive Impairment: People who have difficulty understanding images may benefit from having a text description that conveys the intended meaning.
