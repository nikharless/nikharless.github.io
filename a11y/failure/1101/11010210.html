Expected Result

When a functional image changes dynamically, the text alternative updates to match.

Actual Result

When a functional image changes dynamically, the text alternative does not update to match.

Solution

Code the page to update the text alternative whenever the image changes.

Failing Example

Passing Example

Play/Pause Button

This button uses JavaScript and CSS to change the aria-labelledby value along with the displayed image. The text alternative in this case is attached to the swapped images, and aria-labelledby is used to label the control with the image.

<div class="player" role="button" tabindex="0" aria-labelledby="play">
    <img id="play" src="play.png" class="play" aria-hidden="true" alt="Play">
    <img id="pause" src="pause.png" class="pause" aria-hidden="true" alt="Pause">
</div>

Disabilities Affected

  • Blindness/Visual Impairment: Users need to have a text alternative for functional images so that the images can be interpreted by assistive technology such as screen readers and braille devices.
  • Cognitive Impairment: Users who have difficulty understanding images may benefit from having a text description.
