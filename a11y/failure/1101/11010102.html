Expected Result

An informative inline <svg> has a text alternative that conveys the same information as the image.

Actual Result

Assistive technology users cannot access the information conveyed by the SVG.

Solution

Expose the SVG as an image and give it an accessible name that conveys its information. For example, use role="img" and reference a descriptive <title> element with aria-labelledby.
  1. Add a <title> element as the first child of the the <svg>, and enter the text alternative within.
  2. Add a unique id to the <title>.
  3. Add aria-labelledby to the <svg>, and point it to the <title> element's id.
  4. Add role="img" to the <svg> to ensure that screen readers recognize it as an image and read the text alternative.

Failing Example

No text alternative

This image has no <title> or any other text alternative.

How a screen reader reads it:

  • NVDA: "graphic"

<svg>
    <g id="SVGRepo_tracerCarrier" stroke-width="0">
        ...
</svg>

Passing Example

Preferred: Associated <title>

Using the native HTML <title> tag is the preferred method for providing a text alternative for an inline SVG. However, there may be certain screen reader and browser combinations that do not announce it without also adding role="img" to explicitly identify it as an image and aria-labelledby on the <svg> pointing to the id of the <title>.

How a screen reader reads it:

  • NVDA: "graphic, Accessibility Policy"

<svg role="img" aria-labelledby="a11yPolicy">
    <title id="a11yPolicy">Accessibility Policy</title>
    <g id="SVGRepo_tracerCarrier" stroke-width="0">
    ...
</svg>

aria-label

How a screen reader reads it:

  • NVDA: "graphic, Accessibility Policy"

<svg role="img" aria-label="Accessibility Policy">
    <g id="SVGRepo_tracerCarrier" stroke-width="0">
    ...
</svg>

Disabilities Affected

  • Blindness/Visual Impairment: Users need to have a text alternative for meaningful images so that the images can be interpreted by assistive technology such as screen readers and braille devices.
  • Cognitive Impairment: Users who have difficulty understanding images may benefit from having a text description.
