Expected Result

If a link or button contains only an image, AND the link or button itself doesn't have a text alternative, the image has a text alternative that describes the control's purpose.

Actual Result

A link or button contains only an image, but the image does not have a text alternative, and the link or button does not have an accessible name.

Solution

Add a text alternative that describes the control's purpose using one of the following methods:
  • Add an aria-label attribute to the image element's tag, OR
  • Add an aria-labelledby attribute to the image element's tag, set to the id value of the text element to use as a label.

Disabilities Affected

  • Blindness/Visual Impairment: Users need to have a text alternative for functional images so that the images can be interpreted by assistive technology such as screen readers and braille devices.
  • Cognitive Impairment: Users who have difficulty understanding images may benefit from having a text description.
