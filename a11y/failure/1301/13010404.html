Expected Result

Programmatic headings have visible text.

Actual Result

A programmatic heading is empty.

Solution

  • Place visible text inside the heading tags, OR
  • Remove the extraneous heading code.

Failing Example

<h4></h4>

<h4 aria-label="Invisible Heading"></h4>

Passing Example

Visible Heading

<h4>Visible Heading</h4>
