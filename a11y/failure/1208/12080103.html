Expected Result

Video media that is an alternative to text on the page is clearly labeled as such.

Actual Result

Video media is an alternative to text on the page, but it is not clearly labeled as such.

Solution

Clearly label the media as an alternative to text on the page.

Passing Example

Disabilities Affected

Media which is intended as an alternative to text on the page needs to be clearly labeled as such, so users can find it and so users who expect text alternatives know not to look for them.
