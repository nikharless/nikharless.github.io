Expected Result

Visual indicators of a control's checked state must have a contrast ratio of at least 3:1 with adjacent colors.

Actual Result

Visual indicators of a control's checked state do not have a contrast ratio of at least 3:1 with adjacent colors.

Solution

Change the color of the checked state boundaries to have a contrast ratio of at least 3:1 with adjacent colors.

Failing Examples

Checked Checkbox

The checkbox background has a contrast ratio of only 2:1 with the external background and the checkmark.

Check this box

Checked Radio Button

The radio button background has a contrast ratio of only 2:1 with the external background and the radio button dot.

Check this radio button

Passing Examples

Checked Checkbox

The checkbox background has a contrast ratio of 4.5:1 with the external background and the checkmark.

Check this box

Checked Radio Button

The radio button background has a contrast ratio of 4.5:1 with the external background and the radio button dot.

Check this radio button

Not Applicable

  • Text contrast:
    If the text label changes when the checkbox is checked causing it to fail contrast minimum, file under {{ site.data.1403.1403[14030102].name }}.

Disabilities Affected

  • Color Blindness: Users need to be able to distinguish the control when it's in the checked state.
  • Visual Impairment: Users need to be able to distinguish the control when it's in the checked state
