Expected Result

PDF file has a title describing the content.

Actual Result

PDF file has a title describing the content, but it is not displayed in the title bar.

Solution

Set the PDF preferences to display the title in the title bar.

Adobe Acrobat Pro

  1. Select Menu > Document properties....
  2. In the Document Properties dialog, select the Initial View tab.
  3. Under Window Options, select Document Title from the Show menu.
  4. Activate the OK button.

Examples

Disabilities Affected

Users can easily identify whether the information on the web page is relevant to their needs.
  • Blindness/Visual Impairment: Screen reader users can differentiate content when multiple web pages are open.
  • Motion impaired: Users who rely on audio when navigating between web pages can differentiate content.
  • Cognitive Impairment: Users can identify content by its title.
