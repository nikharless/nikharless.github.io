Expected Result

Shortcut keys do not conflict with existing device and screen reader shortcuts.

Actual Result

An action cannot be performed using only a keyboard, because the shortcut conflicts with an existing user agent or assistive technology shortcut, and there is no equivalent means of achieving the action.

Solution

Change the shortcut to one that does not conflict with existing user agent or assistive technology shortcuts.

Failing Example

Passing Example

Press Shift + Alt + S to open and close the search.

Not Applicable

Disabilities Affected

  • Blindness/Vision Impairment: Screen readers provide users with shortcuts for browsing the web with the keyboard. These shortcuts will override any conflicting shortcuts on a web page.
