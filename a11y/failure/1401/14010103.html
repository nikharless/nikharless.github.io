Expected Result

Color is not used as the only visual means of prompting a response.

Actual Result

Color is used as the only visual means of prompting a response.

Solution

Provide a visual means of conveying the information in addition to color. Some ways to convey information without relying on color:

  • Text
  • A symbol
  • Font weight
  • Pattern
  • Contrast

Failing Example

Highlighted Fields

This example uses yellow highlighting to indicate how to begin the process, but this information is not conveyed to users who can't distinguish color.



Passing Example

Highlighted Fields

In addition to the yellow highlighting, instructions name the field.

Begin by entering the 6-digit ID number into the ID field and clicking Search.
