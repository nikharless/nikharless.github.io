Expected Result

Custom controls have valid roles.

Actual Result

A custom control does not have a valid role.

Solution

Assign an appropriate role to the control (and any sub-components) using the role attribute.

Failing Example

Passing Example

Slider

{% include examples/slider-rating.html %} 
<div id="id-rating-label">Accessibility is the right thing to do.</div>
<div id="id-rating" role="slider" tabindex="0" aria-valuemin="0" aria-valuemax="10" aria-labelledby="id-rating-label">

Toolbar

{% include examples/toolbar.html %} 
<div role="toolbar" aria-controls="textarea1" aria-label="Text Formatting">

Not Applicable

The following items are not applicable to this failure:

  • Hidden:
    <div style="display:none;">
    Does not appear in accessibility tree
  • Role of "none":
    <div role="none">
    Does not appear in accessibility tree

Disabilities Affected

  • Blindness/Vision Impairment: Programmatic roles enable compatibility with assistive technology such as screen readers and screen magnifiers.
  • Motor Impairment: Programmatic roles enable compatibility with assistive technology such as speech recognition software.
