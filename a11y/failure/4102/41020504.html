Expected Result

If a dialog is used to alert the user of a content change, it provides sufficient description of the content change.

Actual Result

A dialog is used to alert the user of a content change, but it does not provide sufficient description of the content change.

Solution

Ensure that the dialog provides sufficient description of the content change.
